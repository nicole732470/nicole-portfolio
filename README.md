## 🧭 What’s inside

This repo is a personal portfolio experience with:

- editorial layouts for career and product storytelling
- visualizations for activity rhythms, maps, and project snapshots
- lightweight Tailwind-driven styling with warm paper tones
- content organized through typed TypeScript data files

---

## 🔧 Key source files

- `app/data.ts` — main biography, projects, links, and site text
- `lib/journey.ts` — travel stories and timeline content
- `lib/thinking.ts` — note-style thinking cards
- `lib/places.ts` — map pins, photo metadata, and city entries
- `lib/movies.ts` — movie recommendations and watch data
- `lib/movie-activity.ts` — heatmap activity builder
- `components/*` — reusable portfolio sections and visual widgets

---

## 🧪 Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and enjoy the editorial portfolio.

---

## 🚀 Deploy

1. Push this repo to GitHub.
2. Import the repo in Vercel and deploy.
3. Set `NEXT_PUBLIC_SITE_URL` to your theme URL.
4. Submit `https://YOUR_DOMAIN/sitemap.xml` to Google Search Console if desired.
